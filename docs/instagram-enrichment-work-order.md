# Instagram 공개 프로필 보강 작업지시서

## 목표와 범위
사용자 승인: 기존 Momcalendar 후보 1,100명의 공개 팔로워 표시값 및 본인 이름/계정으로 판매·홍보하는 사이트 링크 수집. 소유권은 요건이 아니며 공구 상품·플랫폼·프로필 링크 허브도 포함한다. 연락처, 팔로잉 목록, 댓글, 게시물 다운로드는 제외한다.

## 구현 순서
1. 기존 CLI 검색 및 info는 변경하지 않는다. 먼저 저장소 내부 실험용 companion `node scripts/instagram-enrichment.mjs`를 만든다. 설치된 `flucto profile` 명령이 생긴 것으로 보고하지 않는다.
2. 입력 JSON: Instagram 프로필 URL 배열 또는 Flucto 검색 envelope의 videos[].originalUrl. 기존 1,100명은 프로필 URL을 재사용한다. 게시물 입력은 article/header의 작성자만 추출하고 댓글 작성자·로그인 사용자·공동 작업자를 원저자로 추측하지 않는다. 복수 작성자면 ambiguous로 남긴다.
3. 설치된 agbrowse CLI만 사용한다. 기존 브라우저에 새 작업 탭 하나를 만들고 소유한 탭만 사용/종료한다. 쿠키 추출·비공개 API·보안 우회·패키지 설치는 하지 않는다.
4. 프로필 header에서 계정 일치 및 팔로워 링크의 화면 표시값을 읽는다. 반올림 단위와 원문을 보존하며 정밀 정수로 꾸미지 않는다. og:description 같은 캐시 메타데이터로 대체하지 않는다.
5. 프로필 외부 링크를 기록하고 인포크(link.inpock.co.kr / inpk.link)/리틀리 허브만 깊이 1로 확인한다. 프로필의 “외 N개” 버튼은 현재 snapshot의 ref로 열고 dialog의 외부 링크도 읽는다. 링크 텍스트와 출처를 보존한다. 구매/공구/할인/상품 등 명시된 링크는 promotion, 단순 상담/설명서/배송지 입력 등은 other, 불명확한 항목은 candidate로 구분한다. 외부 상품 사이트를 재귀 탐색하지 않는다. 링크 발견은 소유권/영업상태 검증이 아니다.
6. 제한: 기본 10계정, 호출당 최대 50계정, 순차 탐색, navigation 사이 최소 3초, subprocess 45초 제한. 로그인·challenge·호출 제한이면 해당 상태 기록 후 즉시 배치 중단한다. 원인 불명 로딩/파싱 실패도 중단하며 무한 재시도하지 않는다.
7. JSONL 체크포인트에는 입력 URL·프로필 URL·계정·표시 팔로워·링크·관찰 시각·상태를 저장한다. 같은 완료 입력은 resume 시 건너뛴다. 단일 작성자 lock을 사용한다. 대기 상태를 완료로 바꾸지 않는다.
8. 시트 반영은 별도 감독 단계: 계정명이 실제 D열과 일치하는지 확인하고 O:Q만 수정한다. Q에 근거·확인일을 넣는다. 원래 A:N 및 미처리 행은 보존한다. CSV는 새 보강 파일로 저장한다. 화면·새로고침 확인 후에만 저장 성공으로 보고한다.

## 단계별 완료 기준
- 파서 단위 테스트: 정상/빈값/계정 불일치/로그인/제한/복수 작성자/URL 검증/허브 분류/출처 보존.
- CLI 오류 경로: 잘못된 입력과 과다 limit은 브라우저 열기 전에 실패.
- 실브라우저 표본: 프로필 5개 및 게시물 1개로 경로 검증. 시트 표본 반영은 원본 대조 후 수행.
- 표본 이후 다음 소규모 배치를 수행하되 제한이 보이면 중단한다. 1,100명 전체 성공률·무제한 실행을 보장하지 않는다.
- 별도 승인 전 커밋/푸시/릴리스/전역 설치는 금지. 자동 게시·연락·구독·유료 사용도 금지.

## 결과 기록
구현/테스트/실행 증거는 [실행 기록](instagram-enrichment-run-01.md)에 기재한다. 이 문서는 계획이며 완료 증거가 아니다.
